Configuración de impresiones

Consulta los requisitos previos

Para poder enviar impresiones a través de Creality Cloud necesitas una impresora Creality compatible (es decir, una impresora de la marca).

Si tu impresora es antigua y no tiene WiFi, puedes vincularla a través del plugin de OctoPrint. Para ello, previamente necesitarás haber instalado OctoPrint en tu instancia de Home Assistant, o en otro dispositivo conectado a tu impresora (como una Orange Pi o un dispositivo Android).
